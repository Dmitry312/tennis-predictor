# E03A Logistic Regression optimization

Status is planned until the protected validation workflow produces its
machine-readable `E03A.json`. The prior historical comparison reported
35,441 common targets and Logistic Regression log loss 0.61850982.
All comparisons in this experiment use a single new versioned source.
The prior run did not preserve per-target IDs, so changes to the exact
row intersection cannot be reconstructed from its aggregate report.
[Prior validation](https://github.com/Dmitry312/tennis-predictor/actions/runs/46149082580)

The search trains in 2022 and selects on 2023. The selected pipeline
refits on data before each outer fold in 2024 and 2025. These dates have
already been seen and are exploratory. The holdout is excluded at the
source query and runner boundary. All orientations remain paired.
An inner log-loss improvement of at most 0.0002 retains the original.

Candidates include full raw baseline, compact differences, log1p
count and gap differences, signed gap–uncertainty/context interactions,
rating-family leave-one-out, and L1/L2/elastic-net. Mirrored bucket budgets
3/5/7/10 describe the maximum including exact zero, with symmetry allowing
only odd totals. Minimum starting support is 5% of finite values in the
fitted tail for signed bins. Sparse or non-monotone adjacent buckets merge.
Use half-count smoothing, clamp extreme values to the outer bins, and
encode missing or unseen bins as zero. WoE is antisymmetric for signed
pairs. For temporal OOF, January–June of the first training year supplies
maps for later blocks and is omitted from the logistic fit. Each later
block sees only labels from earlier blocks. Inference uses a frozen
full-past map. Conventional WoE uses full-past maps for training too and
must win on 2023. IV selection for conventional candidates uses only
training matches. Symmetry makes invariant context and symmetric features
have zero marginal IV, so context enters the compact design through
interactions and an IV-only rejection rule is avoided.

The report stores exact feature order, constants and duplicates, matrix
rank, correlations and VIF (null under collinearity), distributions,
missingness, matched bin counts/event rates/WoE/IV, PSI by year and
sufficiently populated segments, univariate AUC/Gini, standardized
coefficients, negative candidates, and common outer metrics with UTC
day-block paired confidence intervals.
