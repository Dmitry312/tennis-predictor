# E03C compact rating baselines

Status: registered. Completion requires the protected historical validation
and its versioned report. This comparison uses no 2026 rows and has no
holdout path. Outer 2024/25 was previously observed, so the results are
exploratory. The [E03A/E03B run](https://github.com/Dmitry312/tennis-predictor/actions/runs/46160158114)
published verified metrics but did not list a reusable frozen-source artifact.
E03C compares all candidates on one new validation-only source if no
verified saved bundle is available.

## Decision rule

Use both chronological halves of 2023 for inner selection, fitting each on
earlier matches. Select the simplest candidate within 0.0005 absolute log
loss of the pooled inner best, while requiring each half to be within 0.001
of that same best candidate. Repeat with aggregate tolerance 0.001 as a
sensitivity analysis. For Logistic Regression, complexity is the maximum
feature count across inner fits. For CatBoost, order by depth, trees, then
feature count. Break any remaining tie by inner log loss. Freeze the
candidate before outer 2024 and 2025 refits. The outer metrics and UTC
day-block paired confidence interval describe quality and stability; they
do not select the configuration.

The Logistic Regression reference is the E03A interactions recipe
(L2, C=1, 19 features on the previous snapshot). Test nested removals for
context, Fast Elo, Glicko-2, volatility and repeated experience fields,
then grouped ablations for Glicko, RD, surface and experience. Remove
constants and duplicates based on each fit period. Report the actual
features, standardized coefficients and cross-year coefficient stability,
and PSI for the log-transformed count differences. No WoE is retained
following E03A’s negative inner result.

The CatBoost reference is the original depth-3, 200-tree model. Compare
with shallow joint and compact recipes and deeper depth-4, 280-tree
candidates with Glicko-2 removed. The three deeper feature recipes bracket
the previous E03B result, whose exact recipe is not asserted from the PR
comment alone. Keep the training ratings fixed to the registered default
configuration to isolate feature/model differences. Both estimators score
both side orientations; probabilities are complementary. The report
retains all inner candidates, selected/reference outer metrics, the inner
winner and sensitivity option, with yearly and segment breakdowns.

The protected workflow's `compact` phase produces `E03C.json`. For a frozen
source with `period=validation-only` the same command is available offline.

```bash
uv run --locked --group baseline python scripts/run_rating_optimization.py \
  --compact --source /private/frozen-source --output /private/ratings --reports /private/e03c
```
