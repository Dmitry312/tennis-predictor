# E03B CatBoost optimization

This experiment starts only after E03A writes its report. It reuses the same
source, date cuts and targets. Earlier historical CatBoost log loss was
0.61783069 on 35,441 targets. No claim of full-history improvement is made
until results arrive. [Prior validation](https://github.com/Dmitry312/tennis-predictor/actions/runs/46149082580)

Default predictors are raw numeric rating features. Alternatives include
compact, log-transformed and uncertainty/context interactions, after
dropping exact constants and duplicates on the training partition.
Ablate one rating family at a time. Compare the baseline ratings with
an alternative selected on 2023 alone among four bounded rating changes.
Then search depth 3/4/5/6, learning rate .02/.03/.05/.10 and L2 3/6/12
one coordinate at a time, with a 320-tree ceiling and 30-round early stopping
on 2023. Freeze the resulting tree count before refitting each outer fold.
All models use paired inference, two CatBoost threads and a fixed seed.
The report includes configuration and elapsed time for every candidate,
log loss/Brier/AUC/accuracy/calibration by year and cohort strata, paired
UTC day-block uncertainty, group-level permutation importance and a
bounded SHAP sample on 2023. Correlated features can share or displace
importance. Prefer the original if an outer gain is negligible or unstable.

A fresh optimization workflow extracts only 2021–2025, submits E03A then
E03B, and stores aggregate JSON. If a secret or the existing recipient
certificate is configured, it stores the encrypted source immediately
before fitting. The same checksummed bundle can be passed to
`scripts/run_rating_optimization.py --source ... --output ... --reports ...`.
CMS artifacts can be decrypted locally by the authorized key holder.
